## Репозитории

- Fork — копия исходного проекта на GitHub в аккаунте Krufa2000.
- Clone — локальная копия репозитория для работы через Git CLI.
- origin — мой форк krufa2000-surpo-lab06-collaboration.
- upstream — исходный учебный репозиторий octocat/Spoon-Knife.

## Порядок работы

1. Создать отдельную ветку для изменения.
2. Изменить файл, проверить git diff, выполнить git add и git commit.
3. Отправить ветку в origin командой git push -u origin <ветка>.
4. Создать pull request из рабочей ветки в main своего форка.
5. Проверить изменения и объединить ветки.
6. Обновить локальные данные: git fetch получает изменения, git pull также интегрирует их в текущую ветку.

## Pull request и совместная работа

Pull request — предложение включить изменения, с обсуждением и проверкой кода.
Он отличается от git pull — команды получения и интеграции удалённых изменений.
В команде автор предлагает изменение, другой участник проводит review.
В этой работе один аккаунт демонстрирует процесс между ветками своего форка;
независимая проверка другим участником не выполняется.
